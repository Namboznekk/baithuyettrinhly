# Chuyên đề 6 – Vật lí 10

Website thuyết trình về Trái Đất, Mặt Trăng, nhật thực, nguyệt thực và khu vực thủy triều.

## Bật GitHub Pages
1. Mở Settings → Pages.
2. Chọn Deploy from a branch.
3. Chọn nhánh main và thư mục /(root), nhấn Save.

## Lưu ý về nội dung
Phần thủy triều được để chờ bổ sung vì tài liệu Word hiện có chưa cung cấp nội dung chi tiết cho phần này.
